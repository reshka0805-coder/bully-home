# Bully Home — бультерьеры на двоих (Telegram Mini App)

Игра в духе PrettyCat, только вместо котов — бультерьеры. Пёс живёт на лужайке с живой травой (миска, поилка, диванчик для сна); иконки в стиле «клавиш», неоновые полоски состояния, кнопки-клавиши с неоновой подсветкой.

**Что есть в игре**
- Бультерьер в пиксельной изометрии с пропорциями настоящей собаки (8 направлений): ходит, ест у миски, пьёт из поилки, сидит, спит в лежанке, радуется, отряхивается после мытья.
- Заводишь бультерьера: 6 окрасов (белый, с пятном, тигровый, рыжий, чёрный, лавандовый ✨), цвет ошейника, кличка. Первые 3 дня он щенок, потом подрастает.
- Уход: еда, игра, мытьё, сон. Показатели падают в реальном времени, даже когда игра закрыта. Если погладить пса (тапнуть по нему), растёт уровень дружбы.
- Собаки сами ходят по комнате, а когда хотят спать, идут в лежанку. Окно показывает реальное время суток.
- Прогулки (вместо рыбалки у котов): парк, пляж или лес. Пёс возвращается с находкой. Всего 18 находок трёх редкостей, у каждой своя история, за полный набор дают награду.
- Подарок дня от собаки, у каждого игрока свой.
- Дом из двух комнат: неоновая комната (окно на ночной город) и тёплая кухня (окно в сад). Изначально пустые — технику, мебель и декор покупаешь в магазине (разделы «Комната», «Кухня», «Для пса»). Между комнатой, кухней и двором переходишь стрелками сверху.
- Двор: лужайка с травой на ветру, небо по времени суток и почтовый ящик (записки); предметы двора и 6 расцветок травы. Кнопка ✏️ «Обустроить» включает перетаскивание мебели, лишнее убирается на склад.
- Ярмарка: три мини-игры за монеты — «Лови вкусняшки», «Найди пару» и «Апорт».
- Семья растёт: в доме может жить до 4 бультерьеров.
- **Друзья (Telegram):** во вкладке «Вдвоём» → «Друзья» у каждого свой код друга и ссылка-приглашение (t.me/бот?start=f_КОД). Друзья видят собак друг друга (окрас, уровень, настроение), переписываются прямо в игре и дарят друг другу еду и игрушки. Бот присылает уведомления о новых друзьях, сообщениях и подарках.
- **Вдвоём (общий дом):** общий дом и общие собаки, записки на пробковой доске в комнате, «обнимашки», лента событий. Бот присылает партнёру уведомления: «Серёжа покормил…», «Зефир вернулся с прогулки», «Бублик проголодался».

## Файлы
- `index.html` — сама игра (один файл).
- `dog-sprites.html` — галерея бультерьера: все анимации × 8 направлений, все окрасы, кнопка «скачать спрайт-лист PNG» (кадры 80×86). Кадры рисуются в фоновом потоке, игра не тормозит.
- `bot.py` — сервер общего дома и бот (aiogram 3 + aiohttp, база SQLite). Он же отдаёт `index.html`.
- `requirements.txt` — зависимости.

## Как запустить
1. В @BotFather: `/newbot`, затем скопировать токен.
2. Нужен сервер с публичным **https**: VPS, Railway, Fly.io и т.п. Бот должен работать постоянно, а база должна храниться на диске. Бесплатный Render засыпает и стирает файлы, поэтому для пар он не подойдёт.
3. На сервере:
   ```bash
   pip install -r requirements.txt
   export BOT_TOKEN="123:ABC..."
   export WEBAPP_URL="https://ваш-домен/"
   python bot.py
   ```
   Порт по умолчанию — 8080 (переменная `PORT`). Перед ним нужен nginx/Caddy с https, либо платформа сама даёт https.
4. Бот сам поставит кнопку меню «🏠 Дом». Напиши ему `/start`.
5. *(Необязательно, но так удобнее)* В @BotFather: `/newapp`, указать тот же URL и придумать короткое имя. Это имя положить в `APP_SHORT`, и приглашения будут открывать игру сразу: `t.me/бот/имя?startapp=КОД`. Без него приглашение ведёт в бота, а он присылает кнопку «Открыть дом».

**Как играть вдвоём:** вкладка «Вдвоём» → «Пригласить в Telegram» → отправить ссылку. Партнёр открывает её, заводит своего пса и жмёт «Переехать». Его собаки, монеты и находки переезжают в общий дом. Уведомления придут только тем, кто хоть раз нажал `/start` у бота или разрешил боту писать (игра сама спрашивает это разрешение).

**Без сервера:** если просто залить `index.html` на GitHub Pages, игра будет работать в одиночку и сохраняться на устройстве. Вкладка «Вдвоём» тогда покажет, что нужен сервер.

Тест без Telegram: `DEV=1 python bot.py`, затем открыть `http://localhost:8080/?dev=1:Аня` и во второй вкладке `?dev=2:Серёжа&join=КОД`. На боевом сервере `DEV` не включать.
